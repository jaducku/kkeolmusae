# 껄무새 🦜 제품 요구사항 정의서 (PRD) v1.0

> "살 껄… 참을 껄…" 당신의 소비, 그 돈으로 투자했다면 지금 얼마일까?


| 항목       | 내용                               |
| -------- | -------------------------------- |
| 제품명 (가칭) | 껄무새 (Kkeolmusae)                 |
| 문서 버전    | v1.0 (2026-08-14)                |
| 제품 유형    | 모바일 앱 (iOS / Android)            |
| 단계       | MVP — 가벼운 버전 (계좌 연동 없음)          |
| 핵심 한 줄   | 내 소비의 기회비용을 유쾌하게 보여주는 "후회 시뮬레이터" |


---

## 1. 제품 개요

### 1.1 문제 정의

- 사람들은 자신의 반복 소비(커피, 배달, 택시, 담배 등)가 장기적으로 얼마나 큰 돈인지 체감하지 못한다.
- 기존 가계부 앱은 "기록 → 반성"의 구조라 죄책감을 유발하고, 입력이 귀찮아 금방 이탈한다.
- 투자 커뮤니티에는 이미 "그 돈이면 ○○ 샀다", "살 껄" 같은 후회 밈이 널리 퍼져 있으나, 이를 개인화된 경험으로 만들어주는 제품이 없다.

### 1.2 솔루션

30초 입력만으로 "내 소비를 투자로 바꿨다면 지금 얼마인가"를 극적인 결과 화면으로 보여준다. 가계부가 아니라 **결과 화면이 주인공인 앱**이며, 죄책감이 아닌 **유쾌한 자학과 공유 욕구**를 만드는 것이 목표다.

### 1.3 제품 원칙 (모든 의사결정의 기준)

1. **입력 30초, 결과는 평생 기억** — 결과 화면 도달 전의 모든 마찰을 제거한다. 회원가입 없음.
2. **반성 앱이 아니라 밈 앱** — 카피, 컬러, 캐릭터 모두 "웃긴데 뼈 때리는" 톤을 유지한다.
3. **결과 화면 = 마케팅** — 공유 카드가 곧 광고다. 공유하고 싶지 않은 결과 화면은 실패다.
4. **가볍게, 더 가볍게** — 기능 추가 요청이 오면 기본값은 "거절". MVP는 4화면을 넘지 않는다.

### 1.4 타겟 사용자


| 페르소나             | 설명                                 | 핵심 동기                 |
| ---------------- | ---------------------------------- | --------------------- |
| ① 밈에 진심인 20대 직장인 | 매일 커피 2잔 + 주 3회 배달. 주식/코인 커뮤니티 눈팅족 | "웃긴 결과 나오면 스토리에 올려야지" |
| ② 재테크 입문 30대     | 투자를 시작해야 한다는 압박은 있지만 행동은 못 함       | "이렇게 보니까 진짜 시작해야겠네"   |
| ③ 절약 챌린지 유저      | 무지출 챌린지, 거지방 등 절약 문화 향유층           | "참은 만큼 쌓이는 걸 보고 싶다"   |

## 2. 기능 요구사항

우선순위: **P0 = MVP 필수 / P1 = v1.5 / P2 = 이후 검토**

### 2.1 [P0] 온보딩

- 스플래시 + 훅 문장 1개: "당신의 커피값, 주식이었다면?" — 스킵 가능, 1화면.
- 회원가입/로그인 없음. 데이터는 로컬 저장.
- 껄무새 캐릭터가 첫인사: "어서 와… 후회할 준비 됐어? 🦜"

### 2.2 [P0] 소비 입력 — 프리셋 카드 방식

- 이모지 프리셋 카드 6~8종 제공. 탭하면 선택되고, 금액/빈도를 스테퍼로 조절.


| 프리셋      | 기본값            |
| -------- | -------------- |
| ☕ 커피     | 4,500원 × 주 5회  |
| 🍔 배달    | 22,000원 × 주 3회 |
| 🚕 택시    | 12,000원 × 주 2회 |
| 🚬 담배    | 4,500원 × 하루 1갑 |
| 🍺 술자리   | 40,000원 × 주 1회 |
| 🎮 게임/현질 | 30,000원 × 월 2회 |
| 🛍️ 충동구매 | 50,000원 × 월 2회 |
| ✏️ 직접 입력 | 이름·금액·빈도 자유 입력 |


- 복수 선택 가능. 선택할 때마다 하단에 "월 소비 합계"가 실시간 갱신되어 스케일을 미리 체감시킨다.
- 요구사항: 입력 완료까지 평균 30초 이내 (신규 유저 기준).

### 2.3 [P0] 시뮬레이션 조건 선택

- **기간**: 1년 / 3년 / 5년 / 10년 (기본값 3년)
- **투자 대상** (10개 이내 고정 리스트, 검색 기능 없음):
  - 지수: S&amp;P500(기본값), 나스닥100
  - 국내: 삼성전자, KODEX 200
  - 해외 개별주: 애플, 테슬라, 엔비디아
  - 기타: 비트코인, 금
- 계산 방식: **월 적립식 매수 가정** (해당 월 소비액만큼 매월 매수). 월말 종가 기준, 배당·수수료·환율 변동은 미반영하고 화면에 명시.

### 2.4 [P0] 결과 화면 — 앱의 심장

구성 요소 (위에서 아래로):

1. **헤드라인 카운트업**: "총 소비 16,420,000원" → 슬롯머신 애니메이션 → "지금 가치 **28,910,000원**"
2. **껄무새 리액션**: 놓친 수익 규모에 따라 껄무새 크기/대사가 변화 (§4.3 참조)
3. **체감 환산 카피**: 차액을 현실 물건으로 환산한 한 줄 (카피 DB에서 매칭, §4.2 참조)
4. **그래프**: 소비 누적선(그레이) vs 투자 가치선(네온 그린)이 벌어지는 단일 라인 차트
5. **종목 스와이프 토글**: 같은 입력으로 "비트코인이었다면?" 즉시 재계산 (좌우 스와이프)
6. **CTA 2개**: [공유 카드 만들기] (주 버튼) / [다시 해보기] (보조)
7. 하단 고정 면책 문구 (§6.2)

- 손실 결과(투자 가치 &lt; 소비 총액)의 경우: 레드 대신 그레이 처리 + 껄무새 대사 전환("휴… 안 사길 잘했다 🦜"). 손실도 콘텐츠로 만든다.

### 2.5 [P0] 공유 카드 생성

- 9:16 (인스타 스토리) 비율 이미지 자동 생성 + OS 공유 시트 호출.
- 카드 구성: 껄무새 캐릭터 + 밈 카피 한 줄("나는 커피로 테슬라 12주를 마셨다") + 핵심 숫자 + 앱 로고/QR.
- 카드 템플릿 3종 이상 (숫자 강조형 / 캐릭터 중심형 / 그래프형)에서 선택.
- 1:1 비율(피드용) 병행 지원.

### 2.6 [P1] 참았다 버튼 — 리텐션 장치

- 홈에 "오늘 참았다 🙅" 버튼. 누르면 해당 프리셋 1회분 금액이 **가상 포트폴리오**에 적립.
- 가상 포트폴리오는 선택 종목의 실제 가격을 따라 등락. "참은 돈이 일하는 중" 경험 제공.
- 주간 리포트 푸시: "이번 주 참은 돈 31,500원, 지금 가치 32,100원 🦜"

### 2.7 [P1] 명세서 캡처 분석

- 카드 명세서 스크린샷 업로드 → AI로 품목/금액 추출 → 프리셋 자동 구성.
- 개인정보 이슈로 온디바이스 처리 또는 즉시 파기 원칙, 별도 동의 화면 필수.

### 2.8 [P2] 이후 검토

- 마이데이터/오픈뱅킹 연동 (본격 버전)
- 친구와 후회 배틀 (내 껄무새 vs 네 껄무새)
- 증권사 계좌 개설 제휴 CTA ("지금부터라도 진짜 사기")
- 위젯 (홈 화면에 껄무새 + 오늘의 기회비용)

## 3. 화면 흐름

```
[스플래시/온보딩 1화면]
        ↓
[① 소비 선택] ── 프리셋 카드 탭 + 금액/빈도 조절
        ↓
[② 조건 선택] ── 기간 + 종목 (한 화면에서 처리)
        ↓
[③ 결과 화면] ── 카운트업 → 껄무새 리액션 → 그래프 → 공유
        ↺ 종목 스와이프 / 다시 해보기

```

- 총 4화면. 뒤로 가기 시 입력값 유지.
- ①→③ 도달률이 핵심 퍼널이며, 각 단계 이탈률을 이벤트로 측정한다.

## 4. 밈 심리 설계 — 이 제품의 차별화 핵심

### 4.1 심리 설계 원칙


| 심리 기제            | 적용 방식                                                                                                     |
| ---------------- | --------------------------------------------------------------------------------------------------------- |
| **후회의 게이미피케이션**  | 후회(loss aversion)는 가장 강한 감정 훅이지만, 그대로 주면 앱을 지운다. 껄무새라는 캐릭터에 후회를 "외주"시켜 웃음으로 변환한다. 내가 한심한 게 아니라 껄무새가 우는 것. |
| **자학의 사회적 화폐화**  | "나 이만큼 날렸다ㅋㅋ"는 자랑보다 공유하기 쉽다. 자학 밈은 겸손해 보이면서 화제성이 있어 스토리 공유 장벽이 낮다. 공유 카피는 반드시 1인칭 자학 톤으로 작성한다.            |
| **구체성의 충격**      | "1,200만 원 벌 수 있었다"보다 "아반떼 옵션 풀로 넣을 돈"이 강하다. 추상적 숫자를 체감 가능한 사물로 번역하는 것이 카피의 핵심 기술이다.                       |
| **아슬아슬한 죄책감 조절** | 뼈는 때리되 훈계하지 않는다. "저축하세요" 류의 조언 문구 전면 금지. 결론은 항상 유저 몫으로 남긴다.                                               |
| **반복 가능한 놀이**    | "비트코인이었다면?" 스와이프로 같은 입력을 여러 번 갖고 놀게 한다. 시뮬레이터가 아니라 장난감처럼 느껴져야 한다.                                         |


### 4.2 카피 톤 가이드 + 체감 환산 DB

**톤 규칙**

- 해요체도 합쇼체도 아닌 **친구 말투** ("~했네", "~라고?", "ㅋㅋ" 허용)
- 훈계·조언·금융 전문용어 금지. "복리", "수익률" 대신 "불어난 돈", "몇 배"
- 숫자는 항상 구체적으로, 반올림하지 않고 그대로 (1,249만 원 ← 리얼함이 밈의 재료)

**체감 환산 카피 DB (차액 구간별 예시)**


| 차액 구간          | 환산 카피 예시                |
| -------------- | ----------------------- |
| ~50만 원         | "에어팟 맥스 하나가 커피로 증발했네"   |
| 50~200만 원      | "제주도 한 달 살기 비용을 마셨습니다"  |
| 200~500만 원     | "이 돈이면 유럽 왕복 3번인데요"     |
| 500~1,500만 원   | "아반떼 옵션 풀로 넣을 돈이었다"     |
| 1,500~5,000만 원 | "전세 보증금 올려줄 돈을 배달비로…"   |
| 5,000만 원~      | "이쯤 되면 껄무새가 아니라 껄공룡 🦖" |


- 카피는 서버/설정 파일에서 관리하여 앱 업데이트 없이 갱신 가능하게 한다 (시즌 밈 반영).
- 종목별 특화 카피 병행: 테슬라 → "커피로 테슬라 12주를 마셨다", 비트코인 → "배달 시킬 때마다 사토시가 울었다"

### 4.3 껄무새 캐릭터 정의

- **정체성**: 유저 대신 후회해주는 초록 앵무새. 유저의 소비를 보고 "살 껄~ 참을 껄~" 하고 운다.
- **성격**: 호들갑, 오버리액션, 그러나 미워할 수 없음. 유저를 비난하지 않고 자기가 대신 아파한다.
- **리액션 단계** (놓친 수익 규모 연동):


| 단계   | 조건 (차액)      | 껄무새 상태     | 대사 예시                    |
| ---- | ------------ | ---------- | ------------------------ |
| Lv.1 | ~100만 원      | 갸웃거림       | "음? 살 껄 그랬나? 🦜"         |
| Lv.2 | 100~500만 원   | 날개로 얼굴 가림  | "아… 아… 살 껄…"             |
| Lv.3 | 500~2,000만 원 | 바닥에 드러누움   | "껄!!! 껄!!!! 왜 안 샀어!!!"   |
| Lv.4 | 2,000만 원~    | 영혼 이탈 (흑백) | "…나 먼저 간다… 껄…"           |
| 손실   | 차액 음수        | 안도의 한숨     | "휴… 안 사길 잘했다. 이건 칭찬해 🦜" |


- 결과 화면과 공유 카드의 모든 감정 표현은 껄무새를 통해서만 전달한다 (앱 자체는 중립 유지 → 면책 관점에서도 유리).

### 4.4 공유 루프 설계

```
결과 충격 → 껄무새 리액션에 웃음 → 스토리 공유
→ 친구가 QR/링크 진입 → 30초 입력 → 새 결과 → 재공유

```

- 공유 카드의 QR/링크는 앱 설치 전 **웹 미리보기**(간이 시뮬레이터)로 연결하여 설치 장벽 이전에 경험부터 제공하는 것을 검토 (P1).

## 5. 디자인 무드

### 5.1 무드 키워드

**"밤의 주식 앱에서 열린 코미디 쇼"** — 다크 + 네온의 진지한 투자앱 외형에, 껄무새와 카피가 균열을 내는 대비.

### 5.2 컬러


| 용도    | 컬러                | 비고                 |
| ----- | ----------------- | ------------------ |
| 배경    | #0D1117 (딥 다크)    | 숫자와 네온을 돋보이게       |
| 주 포인트 | #00E88F (네온 민트그린) | 투자 가치선, CTA, 상승 숫자 |
| 보조    | #FFD84D (옐로)      | 껄무새 부리, 하이라이트      |
| 소비/손실 | #8B949E (뉴트럴 그레이) | 레드 금지 — 반성 앱이 아니므로 |
| 텍스트   | #F0F3F6 / #8B949E | 본문 / 보조            |


### 5.3 타이포그래피

- **숫자가 주인공**: 결과 숫자는 화면 세로의 40% 이상. 탭ular(고정폭) 숫자 폰트로 슬롯머신 카운트업.
- 국문 본문: Pretendard. 숫자: Roboto Mono 또는 유사 모노스페이스.
- 카피는 짧게 — 결과 화면 내 어떤 문장도 2줄을 넘지 않는다.

### 5.4 모션

- 카운트업: 1.2~1.8초, ease-out. 최종 숫자 도달 시 미세한 스케일 바운스 + 햅틱.
- 껄무새: Lottie 기반 루프 애니메이션 (단계별 5종 + 손실 1종).
- 그래프: 왼쪽→오른쪽 드로잉 애니메이션, 두 선이 "벌어지는 순간"을 강조.
- 과하지 않게: 화면당 주 애니메이션은 1개. 결과 화면 외에는 모션 최소화.

### 5.5 입력 화면 톤

- 결과 화면의 다크·드라마와 대비되는 **밝고 캐주얼한 카드 그리드** (다크 배경은 유지하되 카드에 컬러/이모지로 경쾌함).
- 스테퍼는 크고 누르는 맛 있게 (햅틱), 금액 변경 시 하단 합계가 통통 튀며 갱신.

## 6. 비기능 요구사항

### 6.1 데이터 &amp; 기술

- 주가 데이터: 무료 시세 API의 **월 단위 종가** (10년 치). 앱 번들에 캐시 + 주기 갱신 → 오프라인에서도 시뮬레이션 동작.
- 환율: 해외 종목은 월평균 환율 적용 (단순화, 화면 명시).
- 사용자 데이터: 서버 저장 없음, 전부 로컬. 회원 시스템 없음 (MVP).
- 성능: 결과 계산은 클라이언트 로컬 연산, 100ms 이내.
- 플랫폼: iOS 15+ / Android 8+ 크로스플랫폼 (React Native 또는 Flutter).

### 6.2 법적/윤리적 요구사항

- 모든 결과 화면·공유 카드에 고정 문구: **"과거 데이터 기반 가상 시뮬레이션이며, 투자 권유가 아닙니다. 과거 수익률은 미래를 보장하지 않습니다."**
- 특정 종목 매수를 권유하는 표현 금지 (카피 검수 체크리스트에 포함). "샀다면 얼마였다"(과거 가정)는 허용, "지금 사라"(미래 권유)는 금지.
- 상승 종목만 기본 노출하지 않도록 종목 리스트에 지수(장기 우상향)와 변동성 자산을 함께 배치하고, 기본값은 지수(S&amp;P500)로 고정.
- 앱 이름/캐릭터: 출시 전 "껄무새" 상표·기존 앱 중복 여부 확인 필요.

### 6.3 분석 이벤트 (최소 세트)

`onboarding_complete` / `preset_selected` / `simulation_run` / `stock_swiped` / `share_card_created` / `share_completed` / (P1) `resist_button_tapped`
